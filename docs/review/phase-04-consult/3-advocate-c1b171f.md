## Recommended position for Maisara

**X-b.** Accept the finding only for rooms with uneven absorption. For uniform α, Kuttruff confirms AX16's total energy exactly. No change to Phase 04. Phase 05 should report sim–measurement errors grouped by the absorption-contrast indicator it already plans, so you can see whether this bias is large in real rooms before paying for a fix.

**1.** Adopt the plan: keep Eyring in Phase 04 and add a* as a Phase 05 reference predictor. Put it in `tools/acoustics`, not `src/sim`, until it is promoted; that way it needs no patch-size AX now and the Phase 10 cache and goldens are untouched. Report γ²-Eyring for information only. On Kuttruff's own Table 5.2 it moves T the wrong way in the absorbing-floor cases he calls most important, so it should not be a candidate to replace Eyring for uneven absorption. Note also that a* is a Lambert-wall (s = 1) result. With the product's typical s of 0.05–0.3 the true answer may lie on the other side of Eyring (§9.4), so only BRAS can decide. Phase-05's "Out of scope: changing the method" still holds, because this only adds a reference comparison; it needs a small `/fix-plan` scope line.

**2.** Adopt the Phase 05 report bound and the validation-only `render_cli` override. Reject showing a humidity-dependent T60 range in the UI. The PRD excludes user-facing atmosphere and its users are producers who "do not have to understand spatial audio". For a user's imagined space AX4 defines the atmosphere; the bound only matters when comparing against a measured room. Add one cheap unit test of `AirAbsorption` against Kuttruff Table 6.1 at 50 % RH. It settles which table AX4 actually matches (Q3) and anchors F6's numbers.

**3.** Adopt the direction: scattered energy must appear in the early part. That directly affects the ER level and EDT that users hear as room size and distance. But split the recommendation in two:
- **Early part (before t_mix):** inject the scattered energy at hit time with Lambert radiosity. This is supported by the corpus.
- **Tail decay:** reject "tail decay from a*" for now. With typical s, most of the energy after t_mix is still specular, so a Lambert decay is no more justified than Eyring. Let item 1's Phase 05 evidence choose the decay source.

Sequence it like item 1: build a Python reference hybrid in Phase 05, then promote it to `src/sim` (a new phase after 05, re-deriving the `open_field` gate) only if it reduces the EDT or C80 error against BRAS. Compute cost is not the obstacle. The interrogator is inconsistent here: item 1 says "promote on evidence" while item 3 commits to the replacement. Meanwhile, add the 10 ms envelope-step metric as reported-only, so the seam that X-a describes is visible in Phase 04/05 artifacts.

**4.** Keep the rule as specified. Reject the proposal to move t_mix to where the specular share is "small". For s ≈ 0.05–0.1 that means 0.7–1.4 s of ISM and up to about 80 000 images in the AQ10 room. The corpus says deterministic late resolution is unnecessary after about 100–140 ms (Vorländer §11.6.1, §15.3), so this buys cost with no perceptual case. Run the 80 ms / 140 ms comparison in Phase 05 instead.

**5.** Adopt the realised-k condition and the capped ISM extension. This matters for v1: the `courtyard` preset is exactly Kuttruff's one-absorbing-wall case, and Phase 12 expects slap echoes that a statistical tail would erase. Do not report q_d. Computed from image lists it reads a flat-room field (all energy along one axis) as about 85 % "diffuse". Report per-axis energy shares instead: these follow from the isotropy definition and catch both 1-D and 2-D fields. Any threshold on them is NOT CHECKABLE. Fix the cap by measurement against AQ10.

**OF.** Keep "E_b = 0 in every band", which is right under any model: there is no diffuse field and Eyring does not apply. Reword the "< −60 dB after 50 ms" criterion as a check of AX16's timing convention, explicitly not a physical expectation, and mark it for re-derivation in whichever phase replaces AX16. With the fixture's own geometry, Lambert floor scattering is estimated at −25 to −45 dB per band. Also flag that AX17's broadband s overstates low-frequency ground scattering (B10).

**C3 / C5.** Ask for a mixed-s reference test before any hybrid is promoted. State the flat-room and 1/t tests with the AQ3 α ≥ 0.01 floor, air absorption, and the ISM cap.
