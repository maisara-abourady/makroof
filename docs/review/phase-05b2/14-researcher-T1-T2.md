## 4. Conflicts between sources
- **The convene note "unbounded near walls" (L83) against F1/F3.** The MCNP infinite variance assumes collisions arbitrarily close. Under AX6 (d ≥ 0.1 m) the T1-F score is bounded by 1/(π d²). Not a conflict between published sources; it is a conditions mismatch.
- **Heinz/Vorländer Fig. 11.38 against SS15.** Heinz's detector is a sphere (corpus, Fig. 11.38). SS15 describes the shadow ray using "the solid angle covered by the receiver". Both imply a finite receiver; neither describes a point receiver. The point form is T1-F's own variant.
