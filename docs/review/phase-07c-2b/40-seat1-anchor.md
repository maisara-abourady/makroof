**Short answer.** Yes, an up-only anchor (A-i) or one with the roles swapped (A-ii) still does the anchor's job. Neither changes the ≥ 5/6 pass mark or the 7/64 chance of passing by guessing. I slightly prefer A-ii.

**1. Reading.** The "3 up, 3 down" anchor in L4-D cannot be built on the L4 scene: the specular share is 0.828, so the deepest step down is −0.82 dB. What I triggered here:
- **S2:** what the control has to show.
- **Strategy B step 4:** a positive control.

**What the anchor is for (my 9-seat1-l4 wording).** It shows that the chain works and that the listener is attending to the tail. It does not measure sensitivity to the envelope.
- In AX47 the step direction mattered because each step happens partway through the programme. An upward and a downward change in time are different stimuli, and the anchor mirrored the 8-up/8-down plan of the scored trials.
- L4's stimuli are static whole files, and L4's own comparison (provisional against exact) has no direction. The anchor therefore has no direction to mirror.
- B against B+3 dB is a uniform 3 dB difference in tail level. That is three times Vorländer's Table 6.1 JND of 1 dB for G (paradigm not stated). Whether it reads as "up" or "down" depends only on which file you call the reference.
- A file at B−3 dB would be a different stimulus pair, but not a different task: both pairs ask the listener to tell apart two tail levels 3 dB apart.

**The pass rate is unchanged.** X is still drawn at random for each trial, so a guesser scores p = 0.5 per trial whatever the labels. P(≥ 5/6) = (1 + 6)/64 = 7/64 = 0.109 under every option. The ≥ 5/6 mark stays.

**Whether A-i and A-ii differ.** No, not for scoring. A bias towards answering "A" cannot raise the expected score when X is random. A-ii only spreads the louder file across both label positions. That costs nothing and keeps the trial plan at 3/3, so L4-D's wording changes less.
