## Challenges to settled decisions

**C-1 — phase-08 AC 3 window "ITD between 0.6 and 0.75 ms" states no estimator.** The window is sized to the human onset ITD (Blauert Ch. 2 Fig. 2.30, ≈ 650 µs; far-source ΔS = (D/2)(φ + sin φ) gives 0.656 ms for a 17.5 cm head). York's own ITD plots for the two SADIE heads read ≈ 0.85 ms (D1) and ≈ 0.77 ms (D2) by an unstated method (F21–F22, C4), while the TH Köln paper gives ≈ 0.625 ms for the same head type as "around 30 taps" at 48 kHz (F23). Either York plots a low-frequency/cross-correlation ITD, which exceeds an onset ITD, or the gate fails as written for both SADIE heads. Ask: name the onset criterion in the AC (and the sign convention, already required) before the first measurement; if the pinned file then measures outside the window, challenge the window with the measurement and the Blauert basis through the interrogator; never widen it to pass. Not a change to the value now.

**C-2 — phase-08 scope 1 "48 kHz, in SOFA format" and scope 3 "diffuse-field equalization of the set (computed in the converter)".** SADIE II was measured at 96 kHz and the SOFA's rate/convention is not stated anywhere readable (F12, N2); the set is already diffuse-field equalised by York (F18). Ask: scope 1 → "SOFA at the record's native rate, read at pin time"; scope 3 → "computed from the set and stored; the header records the source EQ state; for an already-equalised set the computed curve is expected near flat and is reported", so the EQ is applied exactly once (Seat 1's condition) and nothing is applied twice.
