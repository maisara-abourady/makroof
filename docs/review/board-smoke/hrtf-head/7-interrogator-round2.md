**D1-L16 (new): idempotence / "exactly once".** Derivation redone. Stored set S_i = G_Y·H_i. Converter curve C(f) = [Σ w_i |S_i|²]^½ = |G_Y|·[Σ w_i |H_i|²]^½. Output |S_i|/C = |H_i| / [Σ w_i |H_i|²]^½, independent of G_Y.
